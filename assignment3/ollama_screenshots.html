>>> Explain what a static website is in simple terms.

A static website is a website that serves fixed content — the same HTML,
CSS, and JavaScript files are delivered to every visitor without any
server-side processing. Think of it like a printed brochure: what you see
is pre-written and doesn't change based on who's looking at it.

Key characteristics:
- No database or backend logic
- Fast loading (just serving files)
- Easy to host (GitHub Pages, Netlify, etc.)
- Great for blogs, portfolios, documentation

>>> Write a Python function to reverse a string.

Here's a simple Python function to reverse a string:

def reverse_string(s):
return s[::-1]

This uses Python's slice notation. The [::-1] means "start from
the end, move backwards by 1". It works for any string:

reverse_string("hello") # returns "olleh"
reverse_string("python") # returns "nohtyp"

>>> What is the difference between HTTP and HTTPS?

HTTP (Hypertext Transfer Protocol) sends data in plain text, while
HTTPS (HTTP Secure) encrypts the connection using SSL/TLS.

The main differences:
1. Security: HTTPS encrypts all data; HTTP does not
2. Port: HTTP uses port 80; HTTPS uses port 443
3. Certificate: HTTPS requires an SSL certificate
4. URL: HTTPS URLs start with https://
