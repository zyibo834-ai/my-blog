1. Background & Design

This project revives the in-class "Defend Your Thesis" idea as a stable, playable browser game. The player acts as a graduate student protecting a thesis document from academic threats: Bugs, Deadlines, and Peer Reviewers.

The core design goal is simple: protect the thesis for as long as possible while clearing threats and increasing the score. The game begins with a character selection screen, then moves into a real-time Canvas arena.

Methodologist Lab Guardian Night Coder

Each defender has different movement speed, focus recovery, shot strength, and a special ability. This gives the game replay value while keeping the rules readable during presentation.

4. Bonus Features

Integrated AI Agent

The game includes an in-game Advisor panel. It gives tactical tips based on game state, such as low thesis integrity, low focus, deadline clusters, and reviewer clusters. It also answers typed questions about score, focus, thesis integrity, enemies, and character strategy.

Cross-Platform Support

The main version is a static web/PWA app. It runs on Windows, macOS, Linux, and mobile browsers. The Windows executable is included only as an additional local packaging option.

Handling Hallucinations

  • Initial packaging ideas assumed tools like PyInstaller, Electron, or the .NET SDK were available. They were not, so the final primary delivery became a static website.
  • Headless browser screenshots initially failed because of sandboxed crash reporting. The issue was solved by using explicit browser profile folders and elevated execution.
  • The first screenshot showed an empty start state, so a demo URL mode was added to seed visible enemies and Advisor output for documentation only.
